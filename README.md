# إدارة عطل العمال - نظام متطور

## 📋 نظرة عامة

نظام شامل وحديث لإدارة عطل العمال والموظفين في الصيدليات والمؤسسات الطبية. التطبيق بني باستخدام تقنيات ويب حديثة مع دعم كامل للعمل بدون إنترنت (PWA).

## ✨ المميزات الرئيسية

### 🔐 الأمان
- تشفير كلمات المرور باستخدام bcrypt
- التحقق من قوة كلمة المرور
- جلسات آمنة مع timeout تلقائي
- تسجيل شامل للإجراءات (Audit Log)

### 📱 التطبيق
- **Progressive Web App (PWA)** - تثبيت كتطبيق على الهاتف
- **Offline First** - العمل بدون إنترنت والمزامنة التلقائية
- **Responsive Design** - واجهة متجاوبة تعمل على جميع الأجهزة
- **Dark Mode** - مظهر فاتح وداكن قابل للتبديل

### 💾 إدارة البيانات
- قاعدة بيانات محلية (IndexedDB) - بدون خادم
- نسخ احتياطية تلقائية يومية
- استيراد/تصدير البيانات (JSON, CSV)
- طباعة التقارير

### 📊 التقارير والإحصائيات
- تقرير العمال الشامل
- تقرير العطل الشهري
- تقرير الأداء والكفاءة
- تقرير الرصيد السنوي
- سجل التدقيق الكامل

### 👥 إدارة العمال
- إضافة وتعديل وحذف العمال
- تتبع الرصيد السنوي
- تسجيل العطل بأنواعها المختلفة
- البحث والفرز

### 📅 أنواع العطل
- عطلة سنوية (تخصم من الرصيد)
- إجازة مرضية
- عطلة طارئة
- عطلة بدون راتب

## 🚀 البدء السريع

### المتطلبات
- متصفح حديث يدعم IndexedDB و Service Worker
- اتصال بالإنترنت (للمرة الأولى فقط)

### التثبيت
1. انسخ الملفات إلى خادم ويب
2. افتح `index.html` في المتصفح
3. قم بإنشاء حساب جديد أو تسجيل الدخول

### التثبيت كتطبيق
1. افتح التطبيق في المتصفح
2. اضغط على قائمة المتصفح (⋮) أو (⋯)
3. اختر "تثبيت التطبيق" أو "Install app"
4. سيتم تثبيت التطبيق على الشاشة الرئيسية

## 🔧 الإعدادات

### تخصيص القيم الافتراضية

عدّل الملفات التالية في `js/config.js`:

```javascript
DEFAULT_ANNUAL_BALANCE: 21,      // الرصيد السنوي
DEFAULT_WORKING_HOURS: '8',      // ساعات العمل اليومية
AUTO_SAVE_INTERVAL: 30000,       // فترة الحفظ التلقائي (ميلي ثانية)
BACKUP_INTERVAL: 86400000,       // فترة النسخ الاحتياطي (يوم واحد)
```

### تخصيص متطلبات كلمة المرور

```javascript
PASSWORD_REQUIREMENTS: {
  minLength: 8,              // الحد الأدنى للأحرف
  requireUppercase: true,    // يتطلب حرف كبير
  requireNumbers: true,      // يتطلب أرقام
  requireSpecial: false,     // يتطلب رموز خاصة
}
```

## 📖 دليل الاستخدام

### تسجيل عامل جديد
1. اضغط على زر "+ إضافة عامل"
2. أدخل بيانات العامل (الاسم، الموظيفة، إلخ)
3. اضغط "حفظ"

### تسجيل عطلة
1. اختر العامل من القائمة
2. اختر نوع العطلة
3. حدد تاريخ البداية والنهاية
4. أضف ملاحظات إن لزم الأمر
5. اضغط "تسجيل العطلة"

### عرض التقارير
1. اضغط على زر "📊 تقارير"
2. سيتم فتح نافذة طباعة بالتقرير الشامل
3. يمكنك طباعة أو حفظ التقرير

### تصدير البيانات
1. اضغط على زر "🗄 البيانات"
2. اختر صيغة التصدير (JSON, CSV, HTML)
3. سيتم تحميل الملف

## 🔒 الأمان والخصوصية

- **البيانات المحلية**: جميع البيانات تُخزن محلياً على الجهاز
- **بلا خوادم**: التطبيق لا يرسل البيانات إلى أي خادم
- **التشفير**: كلمات المرور مشفرة باستخدام bcrypt
- **Session Timeout**: انتهاء الجلسة بعد 30 دقيقة من عدم النشاط
- **Audit Log**: تسجيل شامل لجميع الإجراءات

## 💡 النصائح والحيل

### النسخ الاحتياطي
- يتم حفظ نسخة احتياطية تلقائياً كل يوم
- يمكنك إنشاء نسخة احتياطية يدوية في أي وقت
- احفظ النسخ الاحتياطية في مكان آمن

### الأداء
- التطبيق يعمل بأفضل أداء على الأجهزة الحديثة
- استخدم النسخة المحسّنة من المتصفح

### العمل بدون إنترنت
- يعمل التطبيق بكامل وظائفه بدون إنترنت
- البيانات تُزامن تلقائياً عند استرجاع الاتصال

## 🐛 استكشاف الأخطاء

### التطبيق لا يحفظ البيانات
1. تحقق من أن IndexedDB مفعّل في المتصفح
2. تأكد من أن لديك مساحة تخزين كافية
3. جرّب مسح بيانات المتصفح وأعد التحميل

### الإشعارات لا تظهر
1. تأكد من السماح بالإشعارات في إعدادات المتصفح
2. تحقق من أن Service Worker مسجل بنجاح

### مشاكل الأداء
1. امسح ذاكرة التخزين المؤقتة
2. أغلق التطبيقات الأخرى
3. أعد تشغيل المتصفح

## 📞 الدعم والمساعدة

للإبلاغ عن مشاكل أو الحصول على الدعم:

2. اطلب مساعدة من فريق الدعم
3. قدم تفاصيل المشكلة والخطوات لتكرارها
